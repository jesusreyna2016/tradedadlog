# Skills de day trading

Copiadas de https://github.com/Jakeschincariol/day-trader-skill (commit 3d0f4ef, licencia MIT, ver LICENSE-day-trader-skill).

11 skills: trader-scanner, trader-news, trader-entry, trader-exit, trader-timemachine,
trader-budget, trader-risk, trader-broker, trader-alerts, trader-analyst, trader-pelosi.

- Escriben su salida en `trader/` en la raíz del repo (ignorado por git: lleva planes, órdenes y el log del broker).
- Las herramientas de la SEC piden `SEC_USER_AGENT="Tu Nombre tu@correo.com"`.
- Ninguna envía órdenes por sí sola; trader-broker necesita el MCP de Alpaca (paper por defecto) y tu "yes".
- Para actualizar: volver a copiar las carpetas `trader-*` desde el repo original.
